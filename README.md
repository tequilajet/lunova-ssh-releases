# Lunova SSH — загрузки

**Lunova SSH** — бесплатный SSH/SFTP-клиент для macOS, Linux и Windows: сохранённые серверы с группами, вкладки с терминалом, двухпанельный файловый менеджер с drag-and-drop, вход по паролю / ключу / ssh-agent, встроенный редактор файлов, шифрование секретов в системном хранилище (Keychain / libsecret / DPAPI) и корректная работа через VPN.

Здесь публикуются **готовые сборки**. Исходный код закрыт (см. [LICENSE](LICENSE)).

**[Планы развития →](ROADMAP.md)** — что уже готово и что появится дальше ([English](ROADMAP.en.md)).

## Скачать

Последняя версия — на странице **[Releases](../../releases/latest)**. Выберите файл под свою систему:

| Система | Файл |
|---|---|
| macOS (Apple Silicon) | `Lunova-SSH-vX.Y.Z-mac-arm64.dmg` |
| Linux (любой дистрибутив) | `Lunova-SSH-vX.Y.Z-linux-x86_64.AppImage` |
| Debian / Ubuntu | `Lunova-SSH-vX.Y.Z-linux-amd64.deb` |
| Windows (установщик) | `Lunova-SSH-vX.Y.Z-win-x64-setup.exe` |
| Windows (без установки) | `Lunova-SSH-vX.Y.Z-win-x64-portable.exe` |

Два архива **Source code (zip / tar.gz)** в списке файлов добавляет сам GitHub к любому релизу — отключить их нельзя. Внутри только эта страница и текст лицензии (несколько килобайт); исходного кода приложения там нет, скачивать их не нужно. Файл `mac-arm64.zip`, если он есть в списке, — служебный: его использует встроенное обновление на macOS.

## Установка

Сборки пока не подписаны сертификатами, поэтому системы при первом запуске предупреждают — это ожидаемо:

- **macOS**: откройте dmg и перетащите приложение в Applications. При первом запуске — правый клик по приложению → «Открыть» → «Открыть» (обход Gatekeeper нужен один раз).
- **Linux (AppImage)**: `chmod +x Lunova-SSH-*.AppImage` и запускайте. **deb**: `sudo apt install ./Lunova-SSH-*.deb`.
- **Windows**: запустите setup.exe; в окне SmartScreen нажмите «Подробнее» → «Выполнить в любом случае».

Обновления: на macOS — встроенные («⇄ → Проверить обновления…»); на Linux и Windows пока скачивайте новую версию с этой страницы.
